# SalesmanPro — AI FinOps & Cost Optimization Strategy

## 1. Executive Summary & Cost-First AI Hierarchy

SalesmanPro delivers enterprise AI capabilities across commerce, WhatsApp, school, and accounting workflows while strictly avoiding unnecessary API costs. The platform enforces an **8-tier cost-first execution hierarchy**:

```text
Tier 1: Deterministic Application Logic (Regex, calculations, database rules)
Tier 2: Authoritative Database Lookups (Real stock, prices, order statuses)
Tier 3: Safe Output Caching (Idempotency replays, static category specs)
Tier 4: Zero-Cost Autonomous Engine (salesmanpro-deterministic-v1)
Tier 5: Free-Tier External Models (Google AI Studio Free Tier, Groq Free Tier)
Tier 6: Ultra-Cheap Balanced Models (Gemini 1.5 Flash @ $0.075/1M tokens)
Tier 7: Advanced Balanced Reasoning (Llama 3.3 70B, GPT-4o-mini)
Tier 8: Premium Multimodal Reasoning (GPT-4o, Claude 3.5 Sonnet, DALL-E 3)
```

## 2. Preventing Unnecessary Model Calls

### A. Authoritative Business Facts Are NEVER Generated by LLMs
- **Product Prices & Taxes:** Retrieved directly from `prisma.product.findUnique()` with calculated VAT. The AI explains the quote or invoice, but never computes or hallucinates totals.
- **Inventory Quantities:** Stock availability is checked directly against `Product.inventoryQuantity`.
- **Order Tracking:** Order status is read from `Order.status` and `ShippingFulfillment.trackingNumber`.

### B. Idempotency & Replay Protection
- Every billable request accepts or generates an `idempotencyKey`.
- Identical requests within a 60-second window do not invoke the AI provider a second time; the first completed response is replayed instantly with 0 token spend.

### C. Context Truncation & Compact Prompts
- Long message threads are bounded to the last 6 messages rather than sending full historical chats.
- Product descriptions receive only necessary fields (`name`, `category`, `brand`, `features`) rather than entire raw Prisma database records.

## 3. The Zero-Cost Primary & Autonomous Fallback Strategy

When a deployment has no funded API credits or third-party API keys are suspended/exhausted, SalesmanPro operates on zero external API marginal cost:

### 1. `salesmanpro-deterministic-v1` (Built-in Autonomous Engine)
- **Marginal API Cost:** $0.00.
- **Latency:** < 15ms.
- **Coverage:** Commerce titles/descriptions, SEO tags, specifications, marketing emails, invoice item extraction, WhatsApp concierge greetings, and school lesson plans.
- **Reliability:** 100% offline uptime, zero network failure modes.

### 2. Free-Tier Cloud Models
- **Google Gemini 1.5 Flash:** Free tier (15 requests per minute, 1,500 requests per day) via Google AI Studio.
- **Groq LPU (Llama 3.1 8B Instant):** Free tier with sub-second response times for customer classification and micro-interactions.

---

## 4. Emergency Kill-Switches & Global Controls

Super Admin has immediate platform-wide circuit breakers in `components/admin/SuperAdminAIControlCenter.tsx`:
- **Global AI Kill Switch:** Instantly suspends all AI invocations platform-wide if an unexpected cost anomaly occurs.
- **Per-Provider Kill Switch:** Disables individual providers (e.g., disable OpenAI if billing thresholds are hit while keeping Groq/Gemini active).
- **Per-Model Disable:** Disables specific expensive models (e.g., disabling `gpt-4o` routes traffic to `gemini-1.5-flash` or `salesmanpro-deterministic-v1`).
- **Per-Action Routing:** Reassigns models on any individual action without deploying code.
