# SalesmanPro Website Builder — Prioritized Defect Register

## Defect Summary & Resolution Status

| Defect ID | Severity | Category | Description | Root Cause | Resolution Status | Verified By |
|-----------|----------|----------|-------------|------------|-------------------|-------------|
| **DEF-001** | CRITICAL | Routing / 404 | Navigating to `/shop`, `/catalog`, or `/all-products` resulted in a 404 `notFound()` error. | `[...pageSlug]/page.tsx` checked `canonicalTemplate.defaultPages` which only defined `slug: "products"`. | **RESOLVED**: Added `resolvePageSlugAlias` and automatic page synthesis fallback in `app/site/[slug]/[...pageSlug]/page.tsx`. | Automated Test |
| **DEF-002** | HIGH | Theme Resolution | 16 standard business categories/variants in `sitedata.ts` (e.g. `Modern Shop (v1)`, `Creative CV`, `Modern Magazine`, `Charity Connect`) silently degraded to `default-site@v1`. | Missing normalized variant entries in `ALIAS_TO_CANONICAL_ID` in `lib/website-builder/registry/aliases.ts`. | **RESOLVED**: Added all 16 missing variants and their normalized forms into `ALIAS_TO_CANONICAL_ID`. | `test-theme-resolution-and-builder.js` |
| **DEF-003** | HIGH | Mascot Integration | SalesmanPro AI Mascot was missing website builder capabilities, preventing administrators from managing themes or publishing via conversational commands. | `MascotModule` type lacked `"website"`, and `actionEngine.ts` / `capabilityRegistry.ts` had zero website operations. | **RESOLVED**: Added `website` module, 6 authoritative capabilities, and action engine handlers for view, update theme, update section, reorder, content generation, and publishing. | Automated Test |
| **DEF-004** | MEDIUM | Mobile Responsiveness | Website Builder Studio left sidebar and right inspector panels were fixed-width on small screens (<1024px), causing horizontal squishing and poor touch usability. | Missing mobile drawer toggles and responsive canvas container constraints. | **RESOLVED**: Implemented slide-out drawer on `< lg` with hamburger toggle button in header, backdrop overlay, and responsive `w-full max-w-[768px]` / `max-w-[390px]` viewport widths. | Visual / Code Review |
| **DEF-005** | MEDIUM | Component Naming | `salon-bookings@v1` had mismatched body component name in registry (`SalonBookingsSite` vs physical file `BookingsSite.tsx`). | Historical file naming inconsistency in `SalonBookingsLayout/body/`. | **RESOLVED**: Mapped dynamically in `BodyComponentMap.tsx` and aliased safely in `categoryHeaderFooterLayoutMap.ts`. | Registry Audit |
| **DEF-006** | LOW | Unsaved History | Browser back button or page reload discarded unsaved configuration edits without warning. | Missing `beforeunload` listener on `hasUnsavedChanges`. | **RESOLVED**: Handled via dirty draft state in `WebsiteBuilderStudio.tsx` and persistent draft saving in `website-service.ts`. | Studio Verification |
| **DEF-007** | MEDIUM | Mascot / Audit | `AIAuditLog.create` failed with `Malformed ObjectID` in MongoDB whenever `userId` was non-hexadecimal (e.g., `"mascot"` or system actions). | MongoDB `@db.ObjectId` constraint on `actorId` field in `AIAuditLog` model. | **RESOLVED**: Updated `recordAuditLog` in `actionEngine.ts` to test for valid 24-character hex ObjectId; sets `actorId: null` and moves non-ObjectId actor string to `details.actor`. | Live DB Test (`qa-validation-suite.js`) |
